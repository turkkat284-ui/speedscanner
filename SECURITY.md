Security Policy
Supported Versions
At this time, we provide security updates and maintenance exclusively for the latest stable release (v1.x). Users on older, pre-release, or experimental branches are encouraged to update to the latest version to ensure they have the most secure and stable experience.

Reporting a Vulnerability
We take the security of this project seriously. If you have found a security vulnerability, we kindly ask you to report it responsibly through the following process:

1. Private Reporting
Please do not report security vulnerabilities via public GitHub Issues. Instead, send a detailed report to turkkat284@gmail.com.

2. Information to Include
To help us triage and fix the issue quickly, please include:

A clear description of the vulnerability.

The potential impact (e.g., system crash, network interference).

Steps to reproduce the issue (including any specific IP or port configurations).

Any recommended fixes or workarounds.

Our Response Process
Once a report is received, we follow these steps:

Initial Response: You will receive an acknowledgment of your report within 3 business days.

Evaluation: We will investigate the issue and determine its severity.

Fix & Release: We aim to release a patch within 15 business days for critical issues.

Disclosure: A public advisory will be posted in the GitHub Security tab after a patch is available.

Ethical Usage and Disclaimer
SpeedScanner is designed for authorized network testing only.

Consent: You must have explicit permission to scan any target network.

Compliance: Users are responsible for complying with local laws and regulations regarding network scanning.

Performance: High-concurrency scanning can be resource-intensive; use responsibly to avoid unintended service disruptions.
